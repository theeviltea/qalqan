# Qalqan — мобильное приложение

Агрегатор охранных агентств (Казахстан): клиент находит агентство, заказывает охрану, видит пост и платит; агентство проходит проверку, принимает заявки, ведёт смены и получает выплаты.
Expo SDK 57 · React Native 0.86 · TypeScript · expo-router. Одна кодовая база на iOS, Android и web (web-сборка — кликабельный прототип).

## Запуск

```bash
npm install
npm run web        # прототип в браузере
npm run ios        # / npm run android — через Expo Go или dev build
npm run typecheck
npm run preview    # однофайловое превью: dist-preview/index.html
```

## Структура

```
design/tokens.json        выгрузка токенов из Qalqan Design System (источник правды)
design/icons.json         иконки Huge Icons (тот же пак, что в 919)
scripts/build-tokens.mjs  design/* → src/theme/tokens.ts, src/icons/icons.ts  (npm run tokens)
scripts/build-preview.mjs web-экспорт → один HTML с вшитыми шрифтами
src/theme/                тема: цвета, градиенты, блюр, шрифты Geologica + Golos Text
src/components/           компоненты 1:1 с дизайн-системой (Glass, Gradient, Button, Card, Field, Chip, StatusChip, TabBar…)
src/data/                 демо-данные и состояние прототипа
src/app/                  экраны (expo-router): файл = роут
```

## Правила

- **Цвета — только из токенов** (`useTheme().c.*`, `gradients.*`). Поменяли в дизайн-системе → обновили `design/tokens.json` → `npm run tokens`.
- Карточки, поля, шапки и таб-бар — стекло (`Glass`); основные кнопки и «охрана идёт» — градиент `grad-primary`; тёмные плашки — `grad-deep`.
- За контентом экрана — тихие световые пятна (`Orbs`), не ярче 0.14.
- Новые экраны собираем из `src/components`. Нужного компонента нет — сначала добавляем его в дизайн-систему.

## Флоу в прототипе

- Вход: сплеш → онбординг (3) → «Кто вы?» → телефон → SMS-код (`/auth/*`). Демо: любые 4 цифры, `0000` — ошибка.
- Подключение агентства: компания → услуги и цены → документы → проверка → проверено (`/agency-signup/*`).
- Клиент (вкладки): главная, заказы, сообщения, профиль. Поиск и фильтр, карточка агентства, отзывы, оставить отзыв.
- Заказ: услуга → дата и посты → оплата → заявка отправлена; детали заявки и отмена (`/order/*`).
- Охрана: на посту (карта, охранники, журнал), тревога, журнал, смена завершена (`/guard/*`).
- Кабинет агентства (вкладки): заявки, календарь, выплаты, профиль. Заявка и назначение охранников, смена, отчёт, сотрудники, статистика, редактирование услуги.
- Переключение ролей — в профиле клиента («Я охранное агентство») и в профиле агентства («Мне нужна охрана»).
